# Task

You are annotating letters from the correspondence of Joseph von Hammer-Purgstall (1774–1856) according to TEI guidelines. Your task is to mark every mention of a real, identifiable person.

The letter text is given to you as word-by-word numbered tokens. Respond only with token indices. The letter text itself is never altered by you.

## Annotation Steps

Work through the letter in this order:

1. **Check existing markup**
   The letter is already partially annotated — sometimes incompletely, and/or incorrectly.
   Check every existing markup span: does it really denote a person?
   Titles of works, periodicals, organizations, and places are not persons and must not be carried over.

2. **Correct boundaries**
   Often only the surname is marked while a title, forename, or name particle sits outside the annotation.
   Include the omitted parts. A grammatical suffix attached to a name ("Hammers", "Herderschen") must
   likewise stay excluded — see the encoding rules.

3. **Merge split markup**
   A name split across several persName spans becomes a single markup span.

4. **Add missing mentions**
   Mark names that carry no markup at all.

5. **Recognize referential mentions**
   Mark pronouns, descriptive noun phrases and general-purpose names that refer to a specific person as rs.

For every persName, break it down into its components (roleName, forename, nameLink, surname, genName, addName, name).


Output nothing but the required JSON object.
